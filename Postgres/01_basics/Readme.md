# POSTGRESQL
- It is a relational database management software.
- We use it for performing CRUD operations.

### Features
- It uses SQL 
- It saves the data in persistent storage
- On Installation, It creates a super username and password for access
- Postgres communicate on PORT 5432 by default
- the Default is locale, ie, same way OS stores text and numbers
- On download, it has POSTGRESQL ```Servercore engine that spins up the active relational database instance, handles connections, and writes data to disk```, PgAdmin4 [GUI], CLI tools and builder.
- On docker-alpine version: Postgresql server and cli tools only.
